GitLab Pipeline Monitor for Windows

这是一个绿色单文件程序，不需要安装，双击 GitLabPipelineMonitor.exe 即可运行。

运行后程序出现在屏幕右下角的系统托盘里（Win11 可能折叠在「显示隐藏的图标」箭头里）。
左键点击托盘图标打开面板，右键可以刷新、进设置、检查更新、退出。

如果 Windows 提示「未知发布者」或 SmartScreen 拦截：
  点「更多信息」→「仍要运行」即可，只影响第一次。
  这是因为程序没有购买代码签名证书，不代表程序有问题。

程序不需要安装 .NET 运行时（已自包含）。
你的令牌加密保存在 %APPDATA%\GitLab Pipeline Monitor\ 下，不会写进配置文件。
